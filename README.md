# Helena Portfolio

## Sobre o projeto
O projeto consiste em um site de portfólio pessoal e acadêmico desenvolvido em HTML e CSS. O objetivo da página é apresentar o perfil de Helena Fernandes, sua trajetória de formação e links para seus estudos de caso e projetos desenvolvidos.

## Contexto acadêmico
O portfólio destaca a formação da autora como estudante do Bacharelado em Ciência e Tecnologia (BCTec) na Universidade Federal de Itajubá (UNIFEI). A disciplina especifica para a criação deste código foi BCTEC019_2026_S2_T02 - COMPUTAÇÃO EM NUVEM E DESENVOLVIMENTO WEB, com conteúdo obteve-se realizações de projetos acadêmicos durante a graduação.

## Tecnologias utilizadas
* **HTML5**: Linguagem de marcação utilizada para a estruturação do conteúdo da página web.
* **CSS3**: Folha de estilo utilizada para a estilização visual, layout (Flexbox e CSS Grid), responsividade e efeitos visuais.
* **Bootstrap Icons**: Biblioteca de ícones importada via CDN para exibição de ícones visuais (como o símbolo do GitHub).
* **Markdown**: Formato do arquivo de documentação para repositório.

## Estrutura do projeto
A estrutura de arquivos no pacote comprimido é composta por:

```text
CriacaoPortfolio 
├── doc
├── img
├── Index.html
├── README.md
└── Style.css
```

* **Index.html**: Arquivo contendo a marcação semântica da página, incluindo menu de navegação, seção principal de cabeçalho, seção sobre mim, cartões de projetos e área de contato.
* **Style.css**: Arquivo contendo a estilização global, definição de variáveis de cores, animações, layouts e regras de responsividade.
* **README.md**: Arquivo de documentação do repositório.

*Nota de inferência*: O código HTML referencia recursos de imagem na pasta `img/` (`Foto profissional.jpeg`, `Imagem DocIA.jpeg` e `Capa do estudo de caso.png`)

## Como executar
Por se tratar de um projeto estático em HTML/CSS, a execução padrão ocorre abrindo o arquivo `Index.html` em qualquer navegador web atualizado. 

## Funcionalidades
* **Navegação estruturada por âncoras**: Barra de navegação fixa no topo com links internos para a rolagens suave até as seções ("Início", "Sobre", "Projetos" e "Contato").
* **Apresentação de perfil profissional**: Exibição de foto, nome e descrição da trajetória acadêmica da autora.
* **Exibição de cartões de projetos (Cards)**: Apresentação gráfica e descritiva de projetos com links externos direcionados para repositórios do GitHub.

## Conhecimentos técnicos identificados
* **Estruturação HTML semântica**: Uso de tags semânticas como `<nav>`, `<main>`, `<section>`, `<ul>`, `<a>`, `<img>` e cabeçalhos (`<h1>` a `<h3>`).
* **Estilização avançada com CSS3**: Uso de variáveis CSS (`:root`), resets globais, propriedades de layout (`flexbox` e `grid`), alinhamento, efeitos de desfoque (`backdrop-filter`) e manipulação de estados (`:hover`, `:active`, `:focus-visible`).
* **Integração de bibliotecas externas via CDN**: Conexão com folha de estilo externa para inclusão de pacote de ícones.
